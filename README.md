- issues :: <https://github.com/halostatue/tableau_redirects_extension/issues>

A Tableau extension for generating redirects because
[Cool URIs don't change][uri].

## Installation

Add `tableau_redirects_extension` to your dependencies in `mix.exs`:

```elixir
def deps do
  [
    {:tableau_redirects_extension, "~> 0.1"}
  ]
end
```

Documentation is found on [HexDocs][docs].
